# Automação/Projeto com Python - DIO <br>
Este repositório contém o script em Python desenvolvido para o desafio prático da DIO.

# O que o código faz?<br>
Este script implementa um pipeline ETL básico que consome dados fictícios de clientes bancários , utiliza a API da OpenAI (GPT-4o-mini) para gerar mensagens de marketing personalizadas sobre investimentos e exporta o resultado em um arquivo JSON
